# chartmux

Install the Chartmux CLI through npm:

```bash
npm install --global chartmux
chartmux demo line
```

This package includes native Chartmux binaries for macOS, Linux, and Windows on arm64 and x64. It does not run installation scripts or download executables after installation.

Source, documentation, and release checksums are available at [github.com/mertdeveci5/chartmux](https://github.com/mertdeveci5/chartmux).
